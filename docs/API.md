## `kinfast`

### `to_mjcf(path, out=None, **kw)`

Convert a URDF/xacro file to MJCF. Returns the MJCF string; writes it to `out` if given. Keyword args are passed to Robot.to_mjcf.

## `kinfast.analysis`

Workspace and dexterity analysis.

### `condition_number(chain, q, link_index, translational: bool = True, rows=None)`

Jacobian condition number sigma_max/sigma_min. (B,). Huge near singularity.

### `joint_limit_margin(chain, q)`

Min over joints of normalized distance to the nearest limit. (B,). 1 = every joint mid-range, 0 = some joint sitting on a limit.

### `manipulability(chain, q, link_index, translational: bool = True, rows=None)`

Yoshikawa manipulability w = sqrt(det(J J^T)). (B,). 0 = singular.

### `sampling_bounds(chain)`

Finite (lower, upper) bounds, one per dof, for drawing random configs.

### `workspace(chain, link_index, n: int = 10000, seed: int = 0, device='cpu')`

Monte-Carlo reachable workspace of a link origin.

## `kinfast.batching`

Run a batched function over a huge batch in bounded-size pieces.

### `ik_chunked(chain: kinfast.compile.CompiledChain, target: torch.Tensor, chunk, no_grad: bool = False, **ik_kwargs)`

Solve IK for a large batch of targets a chunk at a time.

### `map_in_chunks(fn, tensors, chunk, no_grad: bool = False)`

Apply a batched function to slices of dim 0 and concatenate the results.

## `kinfast.codegen`

The kinfast compiler: robot-specific code generation for microsecond single-query kinematics.

### class `CompiledRobot(chain)`

Scalar backend: microsecond single-query FK / Jacobian / IK for ONE robot.

Methods:

- `CompiledRobot.fk(q, link=None)`
  q: sequence of dof floats. Returns (n_links,4,4) array, or (4,4) for one link index.
- `CompiledRobot.ik(target_xyz, link, q0=None, iters=100, damping=0.05, tol=0.0001, restarts=8, seed=0)`
  Position IK, damped least squares with random restarts. Returns (q, err). Single-query, scalar-path throughout.
- `CompiledRobot.jacobian(q, link)`
  Geometric Jacobian (6,dof) at q for a link index. Pure-scalar math.

### `generate_fk_source(chain)`

Generate specialized FK source for this robot.

## `kinfast.collision`

Batched, differentiable sphere-based collision distance.

### class `SphereModel(chain, spheres)`

Bounding spheres attached to links.

Methods:

- `SphereModel.centers_world(q)`
  World-frame sphere centers for batch q. -> (B, S, 3).

### `collision_aware_ik(model: kinfast.collision.SphereModel, target_pos: torch.Tensor, q0: torch.Tensor, link_index: int, obs_centers: torch.Tensor, obs_radii: torch.Tensor, iters: int = 300, refine_iters: int = 200, lr: float = 0.05, refine_lr: float = 0.01, margin: float = 0.02, w_col: float = 10.0, jitter: float = 0.01, seed: int = 0)`

Batched gradient-based IK that reaches target_pos (B,3) while keeping the whole arm at least `margin` clear of the obstacles.

### `distance_to_obstacles(model: kinfast.collision.SphereModel, q: torch.Tensor, obs_centers: torch.Tensor, obs_radii: torch.Tensor) -> torch.Tensor`

Minimum signed distance from any robot sphere to any obstacle sphere. -> (B,).

### `self_distance(model: kinfast.collision.SphereModel, q: torch.Tensor) -> torch.Tensor`

Minimum signed self-collision distance over allowed sphere pairs. -> (B,).

### `com_jacobian(chain: kinfast.compile.CompiledChain, q: torch.Tensor) -> torch.Tensor`

## `kinfast.compile`

Compile a Robot IR into flat tensors for batched kinematics.

### class `CompiledChain(n_links: int, dof: int, link_names: list, link_index: dict, parent: torch.Tensor, joint_origin: torch.Tensor, joint_axis: torch.Tensor, joint_type: torch.Tensor, q_index: torch.Tensor, topo_order: list, lower: torch.Tensor, upper: torch.Tensor, vmax: torch.Tensor, joint_names: list, link_mass: torch.Tensor, link_com: torch.Tensor, link_inertia: torch.Tensor, gravity: tuple = (0.0, 0.0, -9.81), _version: int = 0)`

Fields: `n_links`, `dof`, `link_names`, `link_index`, `parent`, `joint_origin`, `joint_axis`, `joint_type`, `q_index`, `topo_order`, `lower`, `upper`, `vmax`, `joint_names`, `link_mass`, `link_com`, `link_inertia`, `gravity`

Methods:

- `CompiledChain.dtype` (property)
  The float dtype the constants were compiled at.
- `CompiledChain.invalidate_cache()`
  Drop cached derived constants (FK origin rotations, prismatic directions, movable-joint index tensors). FK already notices an in-place edit of a chain tensor on its own, so this is the escape hatch for a change it cannot see. Returns self so it can be chained.
- `CompiledChain.to(device=None, dtype=None)`
  Move and/or cast the compiled constants, in place.

## `kinfast.control`

Classical model-based controllers built on the dynamics layer, plus a semi-implicit Euler simulator to run them in closed loop.

### `computed_torque(chain, q, qd, q_des, qd_des, qdd_des, kp, kd)`

Feedback linearization: tau = M(q) v + c(q,qd) + g(q) with v = qdd_des + kp e + kd de. Closed-loop error obeys e'' + kd e' + kp e = 0.

### `gravity_compensation(chain, q, qd=None)`

tau that exactly cancels gravity at q. (B,dof).

### `pd_gravity(chain, q, qd, q_des, kp, kd)`

PD around q_des with gravity feedforward. kp/kd: scalars or (dof,).

### `simulate(chain, q0, qd0, controller, dt: float, steps: int, record_every: int = 1)`

Roll out the robot under `controller(t, q, qd) -> tau`.

## `kinfast.dynamics`

Batched rigid-body dynamics built on the kinematics layer.

### `coriolis(chain: kinfast.compile.CompiledChain, q: torch.Tensor, qd: torch.Tensor) -> torch.Tensor`

Coriolis + centrifugal generalized force c(q,qd) = C(q,qd) qd. (B,dof).

### `forward_dynamics(chain, q, qd, tau, use_gravity=True)`

qdd produced by tau at state (q,qd). (B,dof).

### `gravity(chain: kinfast.compile.CompiledChain, q: torch.Tensor, g=None) -> torch.Tensor`

Generalized gravity torque g(q) = dU/dq. (B,dof).

### `inverse_dynamics(chain, q, qd, qdd, use_gravity=True)`

tau to realize (q,qd,qdd). (B,dof).

### `mass_matrix(chain: kinfast.compile.CompiledChain, q: torch.Tensor) -> torch.Tensor`

(B,dof) -> (B,dof,dof) symmetric positive-definite mass matrix.

## `kinfast.fk`

Batched forward kinematics: propagate transforms down the tree.

### `fk_rp(chain: kinfast.compile.CompiledChain, q: torch.Tensor)`

World rotations and positions as per-link lists: (wR, wp) with wR[i] (B, 3, 3) and wp[i] (B, 3). The hot path for IK and Jacobians, which never need the assembled 4x4 tensor (assembly is ~a third of FK time at large batch).

### `forward_kinematics(chain: kinfast.compile.CompiledChain, q: torch.Tensor) -> torch.Tensor`

q (B, dof) -> world transforms (B, n_links, 4, 4).

## `kinfast.ik`

Batched damped-least-squares (Levenberg-Marquardt) inverse kinematics.

### `ik(chain: kinfast.compile.CompiledChain, target: torch.Tensor, q0: torch.Tensor = None, link_index: int = None, iters: int = 100, damping: float = 0.05, step: float = 1.0, pos_only: bool = False, tol: float = 0.0001, restarts: int = 1, check_every: int = 10)`

Batched IK. target (B,4,4) -> (q (B,dof), info).

## `kinfast.ik_task`

Weighted task-space IK with a nullspace posture objective.

### `ik_task(chain: kinfast.compile.CompiledChain, target: torch.Tensor, q0: torch.Tensor = None, link=-1, weights=None, q_rest: torch.Tensor = None, w_rest: float = 0.1, iters: int = 100, damping: float = 0.05, step: float = 1.0, tol: float = 0.0001, check_every: int = 10)`

Batched weighted task-space IK. Returns (q (B, dof), info).

### `weighted_dls_step(J: torch.Tensor, e: torch.Tensor, weights=None, damping: float = 0.05, dq_null: torch.Tensor = None) -> torch.Tensor`

One damped-least-squares step with row weights and a nullspace term.

## `kinfast.jacobian`

Batched geometric Jacobian read from the FK frames.

### `jacobian(chain: kinfast.compile.CompiledChain, q: torch.Tensor, link_index: int, world: torch.Tensor = None) -> torch.Tensor`

Pass `world` (from forward_kinematics at the same q) to avoid recomputing FK; callers like IK evaluate both per iteration.

### `jacobian_rp(chain: kinfast.compile.CompiledChain, q: torch.Tensor, link_index: int, rp=None) -> torch.Tensor`

Geometric Jacobian computed from R/p lists (the fast path). rp: (wR, wp) from fk_rp at the same q; computed here if absent.

## `kinfast.lint`

Structural lint for a robot model.

### class `Finding(code: str, severity: str, where: str, message: str)`

One lint result. `where` names the link, joint, or robot it belongs to.

Fields: `code`, `severity`, `where`, `message`

### class `Report(robot_name: str = 'robot', findings: list = <factory>)`

The findings from one `check` call, in the order the rules ran.

Fields: `robot_name`, `findings`

Methods:

- `Report.add(code, severity, where, message)`
- `Report.by_code(code)`
- `Report.codes` (property)
  The distinct rule codes that fired, in the order they first fired.
- `Report.critical` (property)
- `Report.major` (property)
- `Report.minor` (property)
- `Report.ok` (property)
  True when nothing critical was found. Major and minor findings are worth reading but do not stop the model from loading.
- `Report.summary()`
  One line: how many findings, split by severity.
- `Report.to_markdown()`
  Render the report as markdown, grouped by severity, worst first.

### `check(robot, source=None)`

Run every structural rule over a Robot IR and return a `Report`.

### `check_urdf_file(path)`

Same as `check_urdf_string`, reading from disk.

### `check_urdf_string(text)`

Parse URDF text and lint it, with the text kept as the source so that duplicate link names are visible.

## `kinfast.mjcf.emit`

Emit MJCF (MuJoCo XML) from the Robot IR: a URDF -> MJCF converter.

### `emit_mjcf(robot: kinfast.ir.Robot, geometry: bool = True, meshdir: str = '', meshdir_strip: str = '') -> str`

Robot IR -> MJCF string. geometry=False emits a kinematics+inertia-only model (loads anywhere, no assets needed).

## `kinfast.mjcf.parse`

Parse a useful subset of MJCF (MuJoCo XML) into the same Robot IR that URDF uses, so every backend (batched torch, dynamics, the compiler) works on MuJoCo models unchanged.

### `parse_mjcf_file(path: str) -> kinfast.ir.Robot`

### `parse_mjcf_string(text: str, base_dir: str = None) -> kinfast.ir.Robot`

Parse MJCF text. `base_dir` is the directory <include file=...> paths resolve against; without it includes cannot be read and a model that has all of its bodies behind an include raises instead of coming back empty.

## `kinfast.robot`

Ergonomic surface: five-line load + fk/jacobian/ik.

### class `Robot(chain, ee_link=None, ir=None)`

Loaded robot. The dtype of the q you pass decides the working dtype of every method (fk, jacobian, ik, dynamics, collision): the compiled chain's constants are cast to it, so a robot compiled as float32 takes float64 q and returns float64 results. Velocities, accelerations, torques, and IK targets are coerced to the dtype of q (or of the target when q is absent).

Methods:

- `Robot.compile()`
  Generate robot-specific straight-line code for microsecond single-query FK / Jacobian / IK (the scalar backend). Returns a CompiledRobot; the batched torch path on this Robot is unaffected.
- `Robot.dof` (property)
- `Robot.double()`
  Recompile the chain at float64, in place. Returns self.
- `Robot.dtype` (property)
  The float dtype the chain's constants were compiled at.
- `Robot.fk(q, link=None)`
- `Robot.fk_all(q)`
- `Robot.float()`
  Recompile the chain at float32, in place. Returns self.
- `Robot.forward_dynamics(q, qd, tau, use_gravity=True)`
- `Robot.from_ir(robot_ir, repair_model=True, ee_link=None, dtype=torch.float32)`
  Compile a parsed model. `dtype` is the precision the constants are compiled at (default float32); pass torch.float64 for a double chain.
- `Robot.gravity(q, g=None)`
  Generalized gravity torque. g defaults to the model's own gravity vector (MJCF `<option gravity>`, else (0, 0, -9.81)).
- `Robot.ik(target, q0=None, link=None, **kw)`
- `Robot.inverse_dynamics(q, qd, qdd, use_gravity=True)`
- `Robot.jacobian(q, link=None)`
- `Robot.joint_names` (property)
  Movable joint names, ordered by their index in q.
- `Robot.link_id(name)`
  Row of `fk_all` for a named link.
- `Robot.lower` (property)
- `Robot.mass_matrix(q)`
- `Robot.n_links` (property)
- `Robot.parse_notes` (property)
  What the parser approximated or dropped: free joints treated as fixed, bodies left at zero mass, settotalmass scaling. Empty list for a model that needed none.
- `Robot.point_to_point(q0, qf, amax=None, n=100)`
  Time-optimal synchronized trapezoidal move under the URDF's velocity limits (joints with no declared limit fall back to 1 rad/s).
- `Robot.q_index(joint_name)`
  Index into q for a named joint.
- `Robot.random_configs(n, dtype=None)`
  Uniform random configurations inside the joint limits, (n, dof). Revolute joints with infinite limits are sampled over a full turn; prismatic joints with infinite limits raise ValueError. dtype defaults to the chain's compiled dtype.
- `Robot.sphere_model(spheres)`
  Build a collision SphereModel. spheres: {link_name_or_index: [(x,y,z,r)]}.
- `Robot.to(device=None, dtype=None)`
  Move to a device and/or recompile at a float precision, in place.
- `Robot.to_mjcf(geometry=True, meshdir='', meshdir_strip='')`
  Export this robot as an MJCF string (URDF -> MuJoCo). See kinfast.mjcf.emit for what is reproduced and how it is verified.
- `Robot.transform_points(points, q, from_link, to_link='world')`
  Express points given in `from_link`'s frame in `to_link`'s frame (or the world frame). points: (N,3) shared across the batch or (B,N,3), as a tensor or anything torch can make one from. Returns (B,N,3).
- `Robot.upper` (property)

### `load(path, ee_link=None, mappings=None, dtype=torch.float32)`

Load a robot from URDF, xacro, or MJCF (format auto-detected). `mappings` are xacro property overrides, e.g. {"prefix": "left_"}. `dtype` is the precision the chain's constants are compiled at: float32 by default, torch.float64 when you need double-precision kinematics. MJCF <include file=...> paths resolve against this file's directory.

### `load_string(text, ee_link=None, dtype=torch.float32, base_dir=None)`

Same as `load`, from URDF/MJCF text already in memory. `base_dir` is the directory MJCF <include> paths resolve against; kinfast.load fills it in from the file's path.

## `kinfast.zoo`

A registry of public robot descriptions, fetched on demand and cached.

### class `DownloadError(...)`

Raised when a file could not be fetched by urllib or by curl.

### class `Entry(name: str, url: str, format: str, source: str, description: str, extra: tuple = <factory>)`

One robot in the registry.

Fields: `name`, `url`, `format`, `source`, `description`, `extra`

Methods:

- `Entry.filename` (property)
  Basename the file is cached under, taken from the URL.

### class `UnknownRobot(...)`

Raised for a name that is not in the registry.

### class `ZooError(...)`

Base class for every error this module raises on its own.

### `cache_dir()`

Directory the zoo downloads into.

### `clear_cache(name=None, cache_dir=None)`

Delete cached files, for one robot or for all of them.

### `info(name)`

The Entry for `name`, with a helpful error for a name that is not here.

### `list(format=None, contains=None)`

Names in the registry, sorted.

### `load(name, cache_dir=None, force=False, timeout=60.0, **kw)`

Download `name` if needed and load it as a kinfast Robot.

### `names()`

Every registry name, sorted. Same as `list()` with no filters.

### `path(name, cache_dir=None, force=False, timeout=60.0)`

Local path to `name`'s description file, downloading it if it is missing.
